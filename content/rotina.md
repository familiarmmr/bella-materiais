# Rotina semanal em casa — Criança (~4 anos)

Plano prático para a Família. Sessões curtas, lúdicas, sem pressão — para usar **hoje**.

Materiais e links detalhados: [biblioteca-materiais.md](./biblioteca-materiais.md).

---

## Nível da Criança (como calibrar)

Criança **já reconhece e escreve algumas letras e números**, ainda em **aprendizado inicial**.

| Sim | Ainda não |
| --- | --- |
| Reforçar letras/números que ela **já sabe** (orgulho + fluência) | Leitura independente de palavras/frases |
| Traçar / copiar / nomear o que já conhece | Contas formais (+, −, “continhas”) |
| Introduzir **1** letra ou **1** número novo por vez, só quando o conhecido estiver fácil | Pressa para “saber o alfabeto todo” ou “fazer contas” |
| Sons, rimas, contagem com objetos, mais/menos | Decoreba ou folhas longas |

**Regra do passinho:** cada sessão começa com algo que ela **já consegue** (1–2 min de vitória) → depois no máximo **um** desafio pequenino → volta ao fácil se emperrar.

**Cartão “já sei” (façam juntos, 5 min):** listar letras e números que a Criança nomeia ou escreve hoje. Usar essa lista toda semana. Atualizar quando algo novo ficar fácil.

---

## Em uma frase

**4–5 dias · 10–15 min · reforçar o conhecido · um novidade por vez · parar enquanto está gostoso.**

---

## Regras de ouro

| Regra | Na prática |
| --- | --- |
| **Convite, não cobrança** | “Vamos brincar de…?” Se disser não: escolha B ou pular o dia |
| **Um idioma por sessão** | Não misturar **pré-leitura em PT** e **inglês** nos mesmos 10–15 min |
| **Começa fácil** | Abrir com letra/número que ela já sabe escrever |
| **Um novo só** | No máximo **1** letra **ou** **1** número novo na sessão (nunca os dois “novos” juntos) |
| **Ritual de abertura** | Calendário: “Hoje é ___” (30 s, em português) |
| **Corpo antes da mesa** | Se agitada: 2–3 min pular / engatinhar |
| **Fim feliz** | Pasta da Criança: “missão cumprida” |
| **Ok pular** | Dia caótico = descanso conta como cuidado |

**Horário:** o mesmo cantinho do dia. Consistência > perfeição.

## Forma da semana (visão geral)

| Slot | Foco | Como calibrar para o nível dela |
| --- | --- | --- |
| **Dia A** | Português (letras + sons) | 2–3 letras “já sei” → no máx. 1 letra nova (do nome ou próxima) |
| **Dia B** | Matemática (números + quantidade) | Números que já escreve + contar objetos; **sem** continhas |
| **Dia C** | Inglês (só EN) | Música + fala; números EN dos que já conhece em PT |
| **Dia D** | Mundo + motor/cognição leve | Calendário, natureza ou Sol/Lua + memória/massinha |
| **Dia E** (opcional) | Escolha da Criança / reforço | Repetir vitórias da semana (letras/números conhecidos) |
| **Fim de semana** | Livro em voz alta | Adulto lê; a Criança comenta figuras — **sem** cobrança de ler |

Se só der **4 dias:** A → B → C → D.

## Semana 1 — dia a dia (calibrada)

Antes de segunda: façam o cartão **“já sei”** (letras + números) e a lista de materiais. Cada dia: calendário → **1 min do conhecido** → atividade → guardar pasta.

### Segunda — Português (letras do nome + reforço)

| | |
| --- | --- |
| **Tempo** | 10–12 min |
| **Aquecer (fácil)** | Criança escreve **sozinha** 1–2 letras que já sabe (ex.: B ou A). Elogiar. |
| **Fazer** | Cartão do **nome**. Ela aponta as letras que já reconhece. Juntas: traçar no ar → na mesa → copiar **só as letras conhecidas** do nome. Se sobrar ânimo: apresentar **1** letra do nome que ainda não domina (mostrar, nomear, traçar 2× juntas) — sem exigir perfeição. |
| **Não fazer** | Pedir que leia o nome como palavra “de cor” sob pressão; ditado longo. |
| **Fechar** | “Essas letras você já manda muito bem!” |
| **Biblioteca** | §3 Nome próprio |

### Terça — Matemática (números conhecidos + quantidade)

| | |
| --- | --- |
| **Tempo** | 10 min |
| **Aquecer** | Criança escreve 1–2 números que já sabe. |
| **Fazer** | Contar **5** objetos. Pedir: “Me dá **3**” (ou outro número que ela já reconhece). Dois montinhos: “Quem tem **mais**?” Opcional: traçar **um** número conhecido em pontilhado feito à mão. |
| **Não fazer** | Somar/subtrair no papel; “quanto é 2+2?”. |
| **Fechar** | Ela escolhe quantos objetos guardar. |
| **Biblioteca** | §5 Contagem e quantidade |

### Quarta — Inglês (oral + números conhecidos)

| | |
| --- | --- |
| **Tempo** | 8–10 min · **somente inglês** |
| **Fazer** | “Good morning!” Uma música (alphabet **ou** numbers). Contar em EN só até um número que ela já usa em PT (ex.: 1–5). Se quiser letra: apontar no cartão do nome a letra que ela já sabe e dizer o nome em inglês (“B”) — **sem** lição de fonética. |
| **Não fazer** | Folha de leitura EN; misturar explicações longas em PT no meio da sessão. |
| **Fechar** | “Bye-bye!” / high five. |
| **Biblioteca** | §4 Inglês |

### Quinta — Português (sons) + memória

| | |
| --- | --- |
| **Tempo** | 12 min |
| **Aquecer** | Nomear 2 letras “já sei”. |
| **Fazer** | Rimas (“gato / pato — rimam?”). Palmas em **ca-sa**. Memória com **3 pares**. Se fácil: no fim, 1 letra nova do nome **só** para olhar e repetir o nome da letra (não precisa escrever ainda). |
| **Fechar** | Elogiar a espera da vez. |
| **Biblioteca** | §3 Fonologia · §2 Memória |

### Sexta — Matemática (formas/padrões) **ou** Mundo

Escolha **um** (cada bloco ≤ 10 min).

**Formas/padrões:** caça a círculos/quadrados **ou** padrão AB com tampinhas. No fim, se quiser: escrever **um** número conhecido “de presente”. → biblioteca §5  

**Mundo:** clima no calendário **ou** olhar a Lua **ou** massinha Sol + Terra. → biblioteca §6  

### Sábado ou domingo (leve)

Escolha da Criança: repetir a favorita **ou** escrever no ar/quadro as letras e números **já sei** (festa do conhecido) **ou** massinha Sol + Terra + Lua. Livro em PT em voz alta — ela “lê” as figuras, adulto lê o texto.

## Semanas 2+ — modelo reutilizável

Mesmos slots (A–E). Sempre: **conhecido primeiro → no máx. 1 novidade**.

### Como escolher a “novidade” da semana

1. Olhar o cartão **“já sei”**.  
2. Português: próxima letra do nome que ainda não está firme **ou** letra que aparece muito no dia a dia (M, P, S…).  
3. Matemática: próximo número depois do maior que ela escreve com confiança (se escreve até 3, o novo é o 4 — não pular para o 9).  
4. Se a novidade da semana anterior **ainda** não estiver fácil: **repetir** em vez de avançar.

### Rodízio (4 semanas)

| Semana | Dia A · Português | Dia B · Matemática | Dia C · Inglês | Dia D · Mundo |
| --- | --- | --- | --- | --- |
| **2** | Letras “já sei” do nome + achar no cartão; 1 letra a reforçar | Contar até onde for fácil (+1 se confortável); “me dá N” | Mesma música + “What’s this?” (3 objetos) | Estação / roupa do ursinho |
| **3** | Rimas + 1 letra nova (só nomear/traçar juntas) | Formas massinha; escrever 1–2 números conhecidos | Numbers song (se Sem.1 foi alphabet) ou o contrário | Feijão / partes da planta |
| **4** | Som inicial com palavras que começam com letra **já sei** | Padrão AB; mais/menos/igual (objetos) | Hello + *Head, shoulders…* | Bailado dos planetas (adulto = Sol) |
| **5** | Traço: linhas + copiar 2 letras conhecidas (+1 nova se fácil) | 1 folha: só números que ela já traça bem | Contar snacks em EN + please/thank you | Dia e noite |

**Depois da semana 5:** reiniciar o ciclo. Aumentar desafio **só** onde estiver fácil (ex.: 4 pares na memória; contar um pouco mais; 1 letra nova a mais na lista “já sei”).

### Tema “mundo” do mês (Dia D)

1. Dias da semana + clima  
2. Estações e natureza  
3. Sol, Lua e céu  
4. Plantas e animais  

→ biblioteca §6

### Mini-estrutura (15 min)

1. Calendário (30 s)  
2. **Vitória rápida** — letra/número já sei (1–2 min)  
3. Atividade principal (7–10 min)  
4. Fechar / pasta (1–2 min)

## Lista de materiais — Semana 1

- [ ] Cartão **“já sei”** (letras e números que a Criança nomeia/escreve hoje)

- [ ] 1 livro ilustrado PT

- [ ] Giz / lápis grosso

- [ ] 1 folha só com números que ela **já** traça (não a sequência inteira 1–10 de uma vez)
- [ ] Apoio visual de dias/clima
- [ ] Máximo **1–2 páginas** por vez

### Memória (10 min)

3 pares desenhados (sol, bola, estrela).

## Se a Criança estiver cansada ou resistir

| Situação | O que fazer |
| --- | --- |
| **“Não quero”** | Duas opções do **mesmo** foco. Se não: calendário + abraço |
| **Frustração com letra/número novo** | Voltar já para o “já sei”; guardar o novo para outro dia |
| **Quer só escrever o que sabe** | Ótimo — reforço conta. Novidade fica para 2 min no fim, se houver humor |
| **Agitada** | Circuito 3 min ou versão em pé (caça às formas) |
| **Quer só tela** | “Uma música e depois a versão de verdade” |
| **Sessão emperrou** | Cortar para 5 min no sucesso |
| **Dia difícil** | Só calendário + livro |
| **Quer ser professora** | Deixar ensinar ao adulto as letras/números que ela já sabe |

Sinais de **parar:** choro, empurrar material, irritação. Celebrem o que já fizeram.

## Checklist rápido (pais) — fim da Semana 1

- Quais letras/números entraram (ou saíram) do cartão **“já sei”**?  
- Contou até quanto **com objetos** (não de cor só)?  
- Qual sessão ela mais pediu de novo?  
- Tentamos **só 1** novidade por vez?  
- O horário funcionou?
